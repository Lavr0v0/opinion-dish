# 舆论培养皿

一条消息，一百二十个人，七天。看它会长成什么。

你是一个只有 10 个粉丝的小博主。每天发一条消息，看它在性格各异的人之间被转发、被改写，最后长成群体智慧、乌合之众，还是无厘头的玩梗。没有任何一条传播路径是预设的。

在线试玩：https://lavr0v0.github.io/opinion-dish/

整个游戏只有一个文件 `index.html`，下载后用浏览器打开也能玩。

本游戏内含有使用 AI 生成的游戏资产。本作的大部分程序代码、画面、和游戏文本由 Claude生成；玩法方向、六条初始信息及其推演设定由我们提供，并由我们逐轮试玩、提出修改意见。未使用第三方素材。

网页版的字体从 Google Fonts 加载（Noto Sans SC、Jost，均为开源字体）；提交给 TapTap 的离线版本不加载任何外部资源，使用系统字体。
